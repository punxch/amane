# 以 Rust 重写并逐步替代 Python 实现

---
Status: accepted
---

Amane 的功能实现迁移到 `amane-rs/`（Rust + Tauri + Vue3），新实现最终覆盖全部现有功能，随后 Python 实现停止维护。覆盖范围包含超分与 R18 导入。

推进方式为纵向切片，切片只决定顺序，不缩小范围。首个切片覆盖番号解析、多源刮削与聚合、资源物化、条目管理、任务队列与任务日志、库扫描与整理；其后依次为播放、订阅源与文件监控、智能体、超分、R18 导入。

迁移不保证数据库兼容，也不提供存量数据导入：新实现以空库启动，元数据由重新刮削产生。

## 后果

- 迁移期内两套实现并存。桌面安装标识、数据目录与默认端口必须区分，否则两者会互相覆盖同一个数据库与配置文件。
- 既有用户数据与第三方来源插件在迁移后不可用。
- 切片之外的区段（播放、智能体、订阅源、文件监控、超分、R18 导入）在首个切片交付时仍然只有 Python 版本，它们按上列顺序补齐。
- R18 导入依赖外部 PostgreSQL 镜像与原生 `psql`，是唯一保留的第二个数据库。
