# 来源只做内置，不保留第三方插件宿主

---
Status: accepted
---

新实现只提供编译进二进制的内置来源，不引入 CPython 嵌入，也不实现 WASM 插件宿主。

## 考虑过的方案

- **嵌入 CPython 复用既有插件**：把 Python 运行时分发进 Tauri 安装包，跨平台构建链与安装体积的代价高于插件生态带来的收益。
- **WASM 插件宿主**：既有插件全部失效，且需要另行定义 ABI 与宿主能力边界，成本与收益不对称。

## 后果

迁移后既有第三方来源插件不可用。来源在 Rust 侧仍以枚举与 trait 实现组织，新增站点不需要改动宿主与前端。
