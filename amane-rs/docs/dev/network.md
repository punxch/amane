# 出站网络

> 只记录跨模块契约与实测结论。档位表、拒绝状态码与轮换上限在 `crates/net/`.

## 构造顺序

`WebClient::new` 接受已构造的 `RateLimiters`, 因此「限速器先于客户端」由类型系统保证。爬虫工厂必须晚于客户端构造, 并在重建时随之替换; 这条约束在实现工厂的切片中生效。

## 行为边界

- 被拒时轮换档位并重建客户端。重建会丢弃连接池, 轮换是异常路径, 接受这一代价。
- 全部档位被拒即返回失败, 不做无限重试。
- 档位与平台必须配对: 浏览器与操作系统组合错位本身就是识别特征。

## 实测结论 (2026-10-28)

| 站点 | 结果 | 含义 |
|------|------|------|
| `javdb.com` | 正常页面, 未触发轮换 | 指纹方案对 Cloudflare 有效, 可作为首批来源 |
| `www.dmm.co.jp` | 302 跳转到 fanza | 页面路径受地区限制, dmm 只能走 API |
| `javbus.com` | 空响应 | 需要 cookie 或另有路径, 逐站点确认 |

结论: 指纹方案可行, 不阻塞首批站点; dmm 的取数路径改为 API, 与页面型来源分开实现。

## 来源的内容标识

DMM 数字版的内容标识不是番号本身, 由番号按固定规则改写; 数字段超过五位属于 FC2 一类的独立编码体系, 由别的来源处理。规则与用例在 `crates/crawlers/src/dmm.rs`。
