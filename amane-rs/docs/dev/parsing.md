# 番号解析

> 记录解析范围与尚未决策的行为。具体规则与前缀表在 `crates/core/src/number.rs`.

## 覆盖范围

整串解析支持四种形态: FC2、六位数字素人、字母前缀带分隔符、字母与数字连写。自由文本提取按同样四种形态依次匹配, 取第一个命中。

内容类型由前缀表与形态判定, 未命中任何前缀时落到欧美类型。

不支持的形态: 欧美日期型番号 (`vixen.24.01.15`)、素人系数字段的补齐 (`ARA-423` 补成 `261ARA-423`)、从路径分段判定类型。这三类输入按普通文本处理。

## 未决策

无法识别时不产出一个番号, 而是返回错误。造一个番号会污染以番号为键的条目空间; 返回错误则会让一部分文件名不规则的真实文件无法入库。该行为在库扫描已按「返回错误」实现, 如需改动须同时调整扫描的未识别归类。
