# 番号解析

> 记录已移植的范围、与旧实现的差异, 以及尚未决策的行为。具体规则与前缀表在 `crates/core/src/number.rs`.

## 已覆盖

整串解析支持四种形态: FC2、六位数字素人、字母前缀带分隔符、字母与数字连写。自由文本提取按同样四种形态依次匹配, 取第一个命中。

内容类型由前缀表与形态判定, 前缀表与旧实现的表一致; 未命中任何前缀时落到欧美类型。

## 与旧实现的差异

| 行为 | 旧实现 | 当前 |
|------|--------|------|
| 欧美日期型番号 (`vixen.24.01.15`) | 识别为番号 | 不识别 |
| 素人系数字段 (`ARA-423` 补成 `261ARA-423`) | 按站内写法补齐 | 不补齐 |
| 从路径分段判定类型 (`getchu` / 里番 / 欧美目录) | 参与类型判定 | 不参与 |
| 无法识别时的兜底 | 用文件名造一个欧美番号 | 返回错误 |

## 未决策

旧实现对任意文件名都会产出一个番号, 典型结果是把 `not-a-number` 当成 `NOT-A-NUMBER`。这会污染以番号为键的条目空间, 但去掉兜底会让一部分真实文件不再入库。当前实现选择返回错误, 该行为在库扫描切片落地前需要确认。
